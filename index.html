LLM Tools

Simple, powerful tools written entirely by LLMs

With LLMs, creating simple tools is trivial, super fun and should be a no-brainer. I'm very curious about the steady state usefulness of vibe coding. This is an effort to find out the answer. All tools are 100% written by LLMs, with not a single line of manually written code.

The goal is to populate this with tools I use frequently (often on buggy, or shady websites), for each tool to be completely private (run in your browser), have zero build steps (pure HTML/CSS/JS), and ooze fun vibes.

/vid2gif
Convert video files to animated GIFs with cropping, scaling, and frame rate controls.
/json-renderer
Render and explore JSON data.
/timezones
Visualize current time across different timezones.
